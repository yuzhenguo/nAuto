# 네이버 자동 주문 프로그램

Appium을 사용하여 네이버 쇼핑 앱에서 자동으로 상품을 주문하는 프로그램입니다.

---

## 📂 파일 구조

```
네이버자동주문/
├── main_order.py          ← 메인 GUI (실행 파일)
├── naver_order_worker.py  ← 자동화 워커 (19단계 주문 로직)
├── order_manager.py       ← 결재목록.xlsx 읽기/쓰기 관리
├── run_order.bat          ← 실행 배치 파일
├── 개발문서/
│   ├── 결재목록.xlsx       ← 주문 데이터 (필수)
│   ├── 검색입력.png        ← 검색창 이미지 (단계 8)
│   ├── 검색아이콘.png      ← 검색 버튼 이미지 (단계 9)
│   ├── 체크박스.png        ← 체크박스 이미지 (단계 12)
│   ├── 바로구매.png        ← 바로구매 버튼 이미지 (단계 13)
│   ├── 전액사용.png        ← 전액사용 버튼 이미지 (단계 17)
│   └── 숫자/
│       ├── p0.png ~ p9.png ← 비밀번호 숫자 이미지 (단계 19)
└── naver_address_auto/    ← 기존 Appium 헬퍼 모듈 (필요)
    ├── naver_appium.py
    ├── appium_helper.py
    └── devices_config.json
```

## 📋 결재목록.xlsx 컬럼 구조

헤더(1행) 기준으로 자동 감지합니다. 다음 키워드 중 하나가 포함된 헤더를 인식합니다:

| 컬럼 | 인식 키워드 | 설명 |
|------|------------|------|
| 검색어 | 검색어, search, keyword | 상품 검색 키워드 |
| 판매자명 | 판매자명, 판매자, seller | 스토어/판매자명 |
| 상품명 | 상품명, product, 상품 | 상품명 (포함 여부로 매칭) |
| 수취인 | 수취인, 수령인, recipient | 배송지 수취인명 |
| 전화번호 | 전화번호, 전화, phone | 수취인 전화번호 |
| 비밀번호 | 비밀번호, password, pw | 결제 비밀번호 (숫자) |
| 완료여부 | 완료여부, 완료, status | 공백=미처리, Y=완료, F=실패 |

### 예시 데이터

| 검색어 | 판매자명 | 상품명 | 수취인 | 전화번호 | 비밀번호 | 완료여부 |
|--------|---------|--------|--------|----------|----------|----------|
| 서리태환 | 허니스타 | 남유네 서리태환 플러스 3g | 황미여 | 010-3655-8742 | 123456 | |
| 서리태환 | 허니스타 | 남유네 서리태환 플러스 3g | 우진국 | 010-1234-5678 | 123456 | |

## 🚀 실행 방법

### 1. 사전 준비

```bash
# Appium 서버 설치 확인
appium --version

# Appium UiAutomator2 드라이버 설치
appium driver install uiautomator2

# Python 패키지 설치
pip install appium-python-client opencv-python pillow openpyxl numpy
# (easyocr, ddddocr 선택 사항)
```

### 2. ADB 기기 연결

- 핸드폰을 USB 또는 무선으로 연결
- `adb devices`로 연결 확인

### 3. 프로그램 실행

```bash
# 배치 파일로 실행
run_order.bat

# 또는 직접 실행
python main_order.py
```

### 4. GUI 사용법

1. **결재목록.xlsx** 파일 경로 확인 (자동으로 `개발문서/결재목록.xlsx` 로드)
2. **Appium 포트** 입력 (기본값: 7723)
3. **▶ 자동 주문 시작** 버튼 클릭
4. 실시간 로그 모니터링

## 📋 자동화 흐름 (19단계)

| 단계 | 내용 |
|------|------|
| 1~2 | 결재목록.xlsx 미완료 데이터 루프 |
| 3 | 메인 페이지 진입, 7초 대기 |
| 4 | 네이버 플러스 스토어 탭 클릭, 5초 대기 |
| 5 | 팝업 처리 (하루/7일 보지 않기) |
| 6 | 마이쇼핑 클릭, 5초 대기 |
| 7 | 마이쇼핑 검색 버튼 클릭, 2초 대기 |
| 8 | 검색입력.png 이미지 인식 → 검색어 입력 |
| 9 | 검색아이콘.png 이미지 인식 클릭, 5초 대기 |
| 10 | 판매자명+상품명 매칭하여 상품 클릭, 5초 대기 |
| 11 | 구매하기 버튼 클릭, 5초 대기 |
| 12 | 체크박스.png 이미지 인식 클릭, 2초 대기 |
| 13 | 바로구매.png 이미지 인식 클릭, 8초 대기 |
| 14 | 변경 버튼 클릭, 3초 대기 |
| 15 | 스크롤 다운 |
| 16 | 수취인+전화번호로 배송지 매칭 후 클릭, 5초 대기 |
| 17 | 전액사용.png 이미지 인식 클릭, 3초 대기 |
| 18 | 결제하기 버튼 클릭, 5초 대기 |
| 19 | p0~p9.png로 비밀번호 각 자리 이미지 인식 클릭 |

## ⚠️ 주의사항

- 실제 결제가 이루어지므로 테스트 시 주의하세요
- 비밀번호는 엑셀 파일에 평문으로 저장됩니다 (보안 주의)
- 이미지 인식 실패 시 XPath 폴백으로 동작합니다
- 로그는 `naver_order_{기기ID}.log` 파일에 저장됩니다
