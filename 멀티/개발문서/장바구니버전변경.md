기존에 바로구매클릭 하여 주문 한로직을 장바구니 담아서 한꺼번에 결재하는 로직으로 바꿈니다

상품검색후 클릭후 구매하기 누른후 
1. 기존처럼 옵션 체크박스 클릭 합니다
 여기서 변경점이 모든체크 박스 인식후 최대 5개 까지 입니다 

2. 다시 이미지 인식해서 화살표.png 참고해서 존재하면 클릭 합니다 위로 부터 2번째 체크박스 클릭합니다

3. 다시 이미지 인식해서 화살표.png 참고해서 존재하면 클릭 합니다 위로 부터 3번째 체크박스 클릭합니다 (3개 존재하면)

4. 다시 이미지 인식해서 화살표.png 참고해서 존재하면 클릭 합니다 위로 부터 4번째 체크박스 클릭합니다 (4개 존재하면)

5. 다시 이미지 인식해서 화살표.png 참고해서 존재하면 클릭 합니다 위로 부터 5번째 체크박스 클릭합니다 (5개 존재하면)

6 그후 장바구니1.png, 장바구니2.png, 장바구니3.png 중하나 인식 되면 클릭 합니다 


그후 결재목록에서 같은 수취인 같은 순번, 같은 로그인 아이디면  작업미완료 있으면 계속 다시 //android.view.View[@content-desc="네이버플러스 스토어 홈"]/android.widget.Image 클릭 상품페이지.xml구조 참고 

그후 //android.widget.Button[@text="하루 동안 보지 않기"] 존재하면 클릭 7일간 등 있어도 닫기 

다시 //android.widget.EditText[@resource-id="input_text"]  그다음 작업 검색어 입력해서 작업 들어갑니다 기존과 동일 검색어 입력후 상품 찾기 클릭해서 상품 페이지 들어가서 위에있는 로직 반복 합니다 

즉 같은수취인 여러 작업할 상품 들을 장바구니 다담고 한방에 결재 합니다 

마지막에 장바구니 다 담은후에 

//android.view.View[@content-desc="장바구니 1"]/android.widget.Image 존재 하면 //android.view.View[@content-desc="장바구니 1"]/android.widget.Image 클릭 합니다 

장바구니 들어간후 



//android.widget.Button[@text="주문하기 1 개의 상품"]  


주문하기 포함한 버튼 클릭 합니다  1 개의 상품은 가변 장바구니.xml 참고
