### 4.1 본인인증 키패드 (22-12 / 22-13)

`2차페이지2.png` 실제 배치:

```
카드비밀번호4자리  [노란 입력란]
1     2     3
4     5     6
7     8     9
완료   0     ⌫
```

키보드가 노란바 **바로 아래** 4행이다. 화면 하단 빈 곳을 키패드로 쓰면 안 된다.

좌표 계산 우선순위:

1. `2차페이지2.png` bbox에 템플릿 실측 좌표를 비례 환산  
2. 안 되면 `2차페이지1/3` 노란바 bbox 비율  
3. 그것도 없으면 노란바 중심 추정

정상 로그 예:

```
📐 [2차페이지] 키맵 2차페이지2 1=(...,8xx) 4=(...,9xx) 완료=(...,11xx)
🔢 1번째 자리 '4'
👉 키패드 '4' 좌표탭 (2xx, 8xx~10xx)
✅ [22-12] 본인인증 키패드 4자리 입력 완료
👉 [22-13] 키패드 '완료' 좌표 탭
```

잘못된 예전 좌표 예 (빈 곳 탭): `4=(201,1128)`, `7=(201,1315)`, `완료=(201,1502)`
